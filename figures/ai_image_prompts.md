# AI Image Generation Prompts for MEISAI Project

Use these prompts in tools like Midjourney, DALL-E 3, or Stable Diffusion to generate high-quality diagrams matching the "6-Phase Model Framework" structure.

## Global Style Settings (Append to all prompts)
> **Style:** High-end scientific publication style (Nature/Science journal). **Clean isometric 3D infographic** with a **restrained, matte aesthetic**. Pure white background with minimal white margins (maximize content density). Compact, edge-to-edge layout. Elements should have **soft volumetric depth** (like architectural models) rather than flat outlines. Color palette: Professional Academic (Navy Blue, Slate Grey, Muted Teal, Soft Gold). No neon, no glossy reflections, no dark mode. Fonts should be clean sans-serif like Helvetica. Focus on clarity, logical flow, and mathematical elegance.
