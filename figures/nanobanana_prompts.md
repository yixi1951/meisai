# Nano Banana Plugin Prompts (Meisai Project)

Use these prompts inside the Nano Banana input box to generate the 6-Phase Structural Flowcharts.

---

## Prompt for Problem 1 (Fan Vote Reversal)
```text
Create a complex "Left-to-Right" Mermaid.js flowchart for a Bayesian Inverse Problem model.
Structure it into 6 distinct Subgraphs (Phases):
1. Input: "Raw Data" (Dirty Data, Constraints).
2. Formulation: "Mathematical Probabilities" (P(A|B), Priors).
3. Optimization: "Core Engine" (Simulated Annealing Loop).
4. Processing: "Filtering" (Linear Weights, Normalization).
5. Validation: "Check" (Compare Curve A vs Curve B).
6. Output: "Final Results" (Clean Histogram, Error Bands).
Style: Use a professional academic color scheme (Blue/Orange). Make it dense with specific terms like "Posterior", "Likelihood", "MCMC".
Direction: LR.
```

## Prompt for Problem 2 (Mechanism Comparison)
```text

Structure it into 6 phases flowing Left-to-Right:
1. Scenario Setup: "Historical Data" & "Information Theory".
2. Logic Split (Parallel Paths): Path A "Ranking (Rigid/Step)" vs Path B "Percentage (Fluid/Curve)".
3. Simulation Engine: "Counterfactual Re-run" (Merging both paths).
4. Controversy Analysis: "Conflict Detection" (Judge Saving Throw, Bottom-2).
5. Metrics: "Evaluation" (Democracy Deficit, Reversal Rate).
6. Policy Recs: "Trade-off Matrix".
Style: Use distinct colors for the two paths. High density information.
Direction: LR.
```
